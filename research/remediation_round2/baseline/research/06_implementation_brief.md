# Минимальное ТЗ следующего этапа

Профессиональный калькулятор для психиатра в России. Диагноз, препарат и клиническое действие выбирает врач. Реализовать воспроизведение источниковых чисел; исследование сейчас не содержит приложения.

1. Загружать 38 карточек rules/ с версиями источников. Маршрутизировать только разрешённый результат карточки. findings/ — информационные ограничения, reference_rules/ — исключённые иностранные сравнения. Политика РФ обязательна; иностранного дозового fallback нет.
2. Ключ расчёта: МКБ/показание, МНН, продукт/форма, популяция, режим, версия. При F41.2/БАР/смешанных чертах не подставлять универсальный тревожно-депрессивный модуль. Таблица доз КР без формы — карта, не готовая карточка.
3. Вопросы брать из inputs и question_flows.yaml. Начальные выборы/АЛТ/АСТ/типы ИМАО и даты прекращения лекарств независимы. В справочном просмотре коррекции врач вводит действие напрямую; индивидуальное число требует всех применимых источниковых полей. Неоценённое состояние остаётся not_assessed, без числового допуска.
4. Вывод: exact/range/clinician_choice/selected_source_example/insufficient_data/not_applicable. Показывать суточную и разовую дозу, единицы, кратность, форму, источник/версию/локатор, условия удержания/следующего этапа. До проверки входов base-dose карточки — справочное значение, не безусловная доза пациенту.
5. Не предвыбирать границу диапазона; не перемножать модификаторы; не переносить шаг другого показания; не менять единицы CLcr/eGFR; не делить запрещённую форму. Ошибочная/неизвестная единица даёт конкретную причину отсутствия числа.
6. Переносить только выбранные парные контракты. Полная универсальная матрица не заявлена. Составной пароксетин 40→агомелатин — opt-in пример с условиями прекращения календаря. Обратные направления проверяются отдельно.
7. Дополнительные варианты: до 3 по текущей КР/линии и наличию модуля, без собственного рейтинга. Для паники SER/ESC/PAX; для ГТР ESC/DULOX/AGO после проверки применимости и без утверждения превосходства. Прегабалин — отдельная линия. ВенлафаксинXR при ГТР/социальной тревоге — дополнительный исследованный вариант, статус # старой КР и современной инструкции показывать отдельно.

Нужные файлы: [карточки](02_rules.md), [каталог входов](input_catalog.csv), [пять коротких путей](question_flows.yaml), [матрица](switch_matrix.yaml), [источники](sources.json), [ожидания](test_cases.yaml), [пробелы](05_gaps_and_conflicts.md).

Подготовлено 124 ожиданий основного профиля, отдельные случаи findings/, 15 зарубежных сравнений и 4 случая новой почечной формулы. Это подготовленные ожидаемые результаты. После реализации реально проверить обычные/граничные случаи, unknown, единицы/формы, условные шаги, оба направления, повторяемость при той же версии, видимость причин отказа и исключение foreign fallback. Текущий структурный аудит не запуск приложения.

Для завершения текущего исследовательского основания сверить последние реестровые редакции, выполнить независимый клинический разбор и определить процесс реального применения. Готовность технического переноса не клиническая валидация. ML, новые коэффициенты, обязательная генетика, история пациентов и календарь визитов не добавляются.

Ожидания в test_cases.yaml проверяют отдельные параметры/ограничения под условиями карточки. Пропущенные в фрагменте входы имеют состояние not_assessed_by_fragment; они не считаются нормой. Полные синтетические входы уже подготовлены в remediation/full_scenarios.json, отдельно от фрагментов; они не исполнены калькулятором.
